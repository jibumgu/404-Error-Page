# 길 잃은 페이지 (404)

404 에러 페이지를 인터랙티브하게 만든 작품입니다. 페이지를 보고 있는 동안 시간이 쌓이고, 쌓은 시간으로 페이지를 꾸밀 수 있습니다.

- 서버 없이 동작합니다. GitHub Pages에 올리면 바로 쓸 수 있습니다.
- 시간과 구매 기록은 이 브라우저(`localStorage`)에 저장됩니다.

## 구조

```
index.html   화면 구조
styles.css   스타일, 배경과 테마 효과
script.js    시간 지갑, 상점, 구매 기록, 엔딩
effects.js   파티클, 클릭 효과, 커서 효과, 배경 전환
```

## 꾸미기 상점

| 분류 | 아이템 |
|---|---|
| 파티클 | 반딧불, 눈송이, 벚꽃잎, 단풍잎, 빗방울, 비눗방울 |
| 클릭 효과 | 별가루, 색종이 폭죽, 하트 |
| 커서 | 혜성 커서, 반짝이 커서 |
| 배경 | 오로라, 별빛, 네온 그리드 |
| 테마 | 무지개 나침반, 황금 404, 글리치 404 |

아이템 목록과 가격은 `script.js`의 `CATALOG`에 있습니다. 효과는 `effects.js`에 있습니다.

## 로컬에서 보기

저장소 루트에서 정적 서버를 띄우고 브라우저로 엽니다.

```bash
python3 -m http.server 8080
```

`http://localhost:8080/index.html`을 엽니다.

## GitHub Pages로 올리기

저장소 Settings → Pages에서 `main` 브랜치의 루트를 지정하면 배포됩니다.

## 알려진 한계

- 시간과 구매 기록은 브라우저에서 계산됩니다. 개발자 도구로 값을 바꿀 수 있습니다.
- 구매 기록은 브라우저마다 따로 쌓입니다. 다른 기기에서는 이어지지 않습니다.
- 브라우저 저장소를 지우면 기록도 사라집니다.
